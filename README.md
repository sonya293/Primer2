# Магазин услуг (React + Vite + Node.js API + SQLite)

Лабораторная работа №4: каталог услуг, корзина и заказы на сервере, авторизация и регистрация,
отзывы, личный кабинет, роли администратор / клиент, интеграция с серверным API.

## Запуск
Нужен Node.js **22.5 или новее** (сервер использует встроенный модуль `node:sqlite`).

    npm install
    npm run dev:all     # сервер API (порт 3001) и фронтенд (порт 5173) вместе

Либо в двух терминалах: `npm run server` и `npm run dev`. Откройте http://localhost:5173.
База `server/shop.db` создаётся и заполняется автоматически при первом запуске сервера
(чтобы сбросить данные — остановите сервер и удалите этот файл). Если файл остался от ЛР3,
новые таблицы и колонки добавятся к нему автоматически.

## Что реализовано (по пунктам задания)
- **2.1 Каталог** — список услуг приходит из API; название, описание, длительность, цена, скидка,
  рейтинг. Фильтры: категории, цена «от–до», поиск по названию, сортировка. Категория и рейтинг
  подтягиваются на сервере через JOIN.
- **2.2 Корзина** — хранится в БД (`cart_items`), у каждого пользователя своя, сохраняется после
  выхода. Добавление, изменение количества, удаление, очистка, итоговая сумма. Цены и скидки считает сервер.
- **2.3 Заказ** — кнопка «Оформить заказ»: адрес доставки и дата доставки (дата не раньше сегодняшней
  и не позже чем через год; проверяется и в браузере, и на сервере), способ оплаты.
- **2.4 Вход** — email + пароль, ошибки полей и ошибка «неверный email или пароль».
- **2.5 Регистрация** — имя, email, телефон, пароль (+ повтор пароля), проверка email и телефона.
- **2.6 Отзывы** — окно «Отзывы» у каждой услуги: оценка 1–5 и комментарий, один отзыв на услугу
  (его можно изменить или удалить); оставлять могут только вошедшие клиенты.
- **2.7 Личный кабинет** — вкладки: «Мои заказы» (дата, адрес, статус, состав), «Личные данные»
  (ФИО, email, телефон, адрес по умолчанию), «Смена пароля».
- **2.8 Загрузка и ошибки** — спиннер и сообщение с кнопкой «Повторить» для каждого запроса.
- **Роли** — `admin` и `client`. Администратор в разделе «Админка» добавляет, изменяет и удаляет:
  услуги, категории, купоны, пользователей, заказы (смена статуса и удаление), отзывы.
  Роли и служебные таблицы не редактируются.
- **Забыли пароль?** — ссылка на странице входа: email → одноразовый код (15 минут, 5 попыток)
  → новый пароль. Почты в учебном проекте нет, поэтому код показывается на экране (и в консоли сервера).
- **Навигация и выход** — верхняя панель со ссылками и кнопкой «Выйти». Гость, зашедший в корзину
  или кабинет, отправляется ко входу и после входа возвращается обратно.

## База данных (server/db.js)
- **roles**, **users** (email, хэш пароля scrypt, телефон, адрес по умолчанию, роль, купон), **coupons**
- **categories**, **services** (удалённая услуга скрывается флагом `is_active`, старые заказы сохраняются)
- **cart_items** — корзина пользователя (уникально пара «пользователь + услуга»)
- **orders** — заказ: адрес, дата доставки, статус (`new`, `processing`, `done`, `cancelled`)
- **appointments** — позиции заказа (услуга, количество, цена со скидкой)
- **payments** — платежи (сумма, способ, статус)
- **reviews** — отзывы (оценка 1–5, комментарий, уникально «пользователь + услуга»)
- **password_resets** — коды восстановления пароля

## API (server/index.js)
| Метод и путь                                  | Доступ  | Назначение                                |
|-----------------------------------------------|---------|-------------------------------------------|
| POST /api/auth/register, /login               | все     | регистрация и вход (возвращают токен)     |
| POST /api/auth/forgot, /api/auth/reset        | все     | восстановление пароля по коду             |
| GET  /api/auth/me                             | вошёл   | текущий пользователь                      |
| PUT  /api/profile, /api/profile/password      | вошёл   | личные данные, смена пароля               |
| GET  /api/services, /api/categories           | все     | каталог и категории                       |
| GET  /api/services/:id/reviews                | все     | отзывы об услуге                          |
| POST /api/services/:id/reviews                | вошёл   | оставить отзыв                            |
| PUT/DELETE /api/reviews/:id                   | автор / админ | изменить / удалить отзыв            |
| GET/POST/DELETE /api/cart, PUT/DELETE /api/cart/:serviceId | клиент | корзина в БД              |
| POST /api/orders, GET /api/orders             | клиент  | оформить заказ, мои заказы                |
| /api/admin/categories, /services, /coupons, /users (POST/PUT/DELETE) | админ | управление справочниками |
| GET /api/admin/orders, PUT .../:id/status, DELETE .../:id | админ | заказы                      |
| GET /api/admin/reviews                        | админ   | все отзывы                                |

Сервер проверяет **все** поля независимо от интерфейса: типы, длины, формат email и телефона, диапазоны чисел,
существование даты, права доступа (401/403) и принадлежность данных пользователю.

## Система скидок
- Из 20 услуг у 6 (30%) есть общая скидка; у пользователя может быть один купон (выдаёт администратор).
- К услуге применяется **бо́льшая** из двух скидок, они не суммируются. Цена пересчитывается на сервере.

## Структура
- server/ — API (index.js) и база данных (db.js)
- scripts/dev.js — одновременный запуск сервера и Vite
- src/api.js — обёртка над fetch (токен, обработка ошибок сети и сервера)
- src/hooks/useFetch.js — загрузка данных: loading / error / повтор
- src/context/ — тема, авторизация, корзина (работает через API)
- src/pages/ — Catalog, Cart, Login, Register, ForgotPassword, Dashboard, Admin, NotFound
- src/components/ — Navbar, ServiceCard, ReviewsModal, Field, Status, RequireAuth, admin/*
- src/utils/ — pricing.js (скидки, форматы), validators.js (проверка форм)

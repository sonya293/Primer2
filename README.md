# Магазин услуг (React + Vite + Node.js API + SQLite)

Лабораторная работа №3: каталог услуг, корзина, авторизация, система скидок и категорий,
интеграция с серверным API.

## Запуск
Нужен Node.js **22.5 или новее** (сервер использует встроенный модуль `node:sqlite`).

    npm install
    npm run dev:all     # сервер API (порт 3001) и фронтенд (порт 5173) вместе

Либо в двух терминалах: `npm run server` и `npm run dev`. Откройте http://localhost:5173.
База `server/shop.db` создаётся и заполняется автоматически при первом запуске сервера
(чтобы сбросить данные — остановите сервер и удалите этот файл).

## База данных (server/db.js)
- **roles** — роли (admin, client)
- **users** — пользователи (email, хэш пароля scrypt, роль, персональный купон)
- **coupons** — виды скидочных купонов (название, процент)
- **categories** — категории услуг
- **services** — услуги (категория, название, описание, длительность, цена, общая скидка)
- **appointments** — записи (пользователь, услуга, количество, цена со скидкой, дата)
- **payments** — платежи (сумма, способ, статус)

## API (server/index.js)
| Метод и путь                              | Доступ  | Назначение                               |
|-------------------------------------------|---------|------------------------------------------|
| POST /api/auth/login, /api/auth/register  | все     | вход и регистрация (возвращают токен)    |
| GET  /api/auth/me                         | вошёл   | текущий пользователь                     |
| GET  /api/services, /api/categories       | все     | каталог и категории                      |
| POST /api/checkout                        | вошёл   | оформление корзины: платёж + записи      |
| GET  /api/appointments                    | вошёл   | мои записи                               |
| POST /api/admin/categories                | админ   | добавить категорию                       |
| POST /api/admin/services                  | админ   | добавить услугу                          |
| PUT  /api/admin/services/:id/discount     | админ   | общая скидка на услугу                   |
| GET/POST /api/admin/coupons               | админ   | виды купонов                             |
| GET  /api/admin/users                     | админ   | пользователи                             |
| PUT  /api/admin/users/:id/coupon          | админ   | выдать/снять персональный купон          |

## Система скидок
- Из 20 услуг у 6 (30%) есть общая скидка.
- У пользователя может быть один купон; выдаёт его администратор (страница «Админка»).
- К услуге применяется **бо́льшая** из двух скидок (скидка на услугу или купон), они не суммируются.
  Цена пересчитывается на сервере при оформлении, поэтому подделать её на клиенте нельзя.

## Категории
В каталоге слева — `aside` с чекбоксами по каждой категории (можно выбрать несколько;
если ничего не выбрано — показаны все услуги). Категория, добавленная админом, сразу
появляется в списке: каталог каждый раз загружает категории с сервера.

## Структура
- server/ — API (index.js) и база данных (db.js)
- scripts/dev.js — одновременный запуск сервера и Vite
- src/api.js — обёртка над fetch (токен, обработка ошибок сети и сервера)
- src/hooks/useFetch.js — загрузка данных: состояния loading / error / повтор
- src/context/ — тема, корзина (id + количество), авторизация (токен в localStorage)
- src/pages/ — Catalog, Cart, Login, Register, Dashboard, Admin, NotFound
- src/components/ — Navbar, ServiceCard, Status (загрузка/ошибка), RequireAuth
- src/utils/pricing.js — расчёт скидок и форматирование
